# 桌面 UI 改版与验收

2026-11-09

## 设计与行为

本轮重新组织 Agents、Providers、Gateway、Plugins、Usage 和 Settings 六个页面。使用白灰与炭黑底色、小面积蓝色强调、连续列表和统一留白；正文、标题、辅助信息和主要操作具有独立层级。页面、输入框与 Material 控件共用 `workspace_scheme`，Usage 插件也使用同一颜色来源。

| 页面 | 改动 |
| --- | --- |
| Agents | 默认显示工具名称、配置状态与当前模型；点击一行展开该工具的模型与连接操作。配置路径按需展开，关闭编辑区保留草稿和有效预览。 |
| Providers | 对齐名称、服务地址、模型数、状态和操作；添加/保存作为主要按钮，表单按基本信息、连接、凭据与模型分组。 |
| Gateway | 突出真实运行状态和当前连接地址；版本与模型数对齐，监听地址设置独立分组。 |
| Plugins | 连续行展示名称、来源、真实状态和启停动作；空列表与搜索无匹配有五语反馈。 |
| Usage | 对齐真实请求数和 token 统计；保留未知值与覆盖率，宽窗数字分列，窄窗上下重排。 |
| Settings | 外观和语言有明确选中态、简短说明与统一间距。 |

宽度不小于 1040px 时使用完整侧栏，600–1039px 使用图标导航，小于 600px 使用底部导航。高度不足 480px 时缩减固定页头；供应商表单在高度不足 600px 时缩小组间距和操作栏，把保存生效说明放入滚动内容，为字段保留空间。现有五语入口、保存、断开恢复、错误反馈和配置归属约束保留。

目标模型摘要始终保留在展开的操作区，即使搜索结果已过滤掉该模型。换模预览开始后维持同一按钮和焦点句柄，忙碌状态只改变可用性。新增回归检查覆盖连接设置的键盘开合、过滤后的目标与忙碌焦点，以及收起 Agent 后保留模型和预览。初次展开尚未读取的 Agent 时触发配置读取；已读取状态的展开与收起保留草稿。

## 视觉检查中修正的问题

首轮使用生产 GPUI 组件生成截图，检查整组联系表，再放大关键页面与窄窗。根据实际画面完成以下修正：

- Material tonal toggle 的选中态原先使用灰色，改为统一的蓝色选中背景及前景，覆盖导航、外观、语言和模型选择。
- Agent 断开恢复按钮不再占满整行。窄窗将折叠按钮并入身份行，模型标签与值允许同行或自然换行。
- 360×360 供应商编辑页原先只能显示分组标题。缩减固定头尾，保留完整字段的可视区域。
- 网关失败原因移至状态与动作之后，短窗首屏能先看到问题及恢复建议。
- 凭据场景按已布局的字段锚点滚动，显式执行离屏环境的下一帧回调后截取。最终 360×360 浅深截图均完整显示密钥遮蔽和辅助说明。

## 复现

桌面是独立 Rust workspace，使用仓库锁定的 Rust 1.99.1 与 GPUI/Material 版本。输出必须位于源码仓库之外的新目录。

```sh
CARGO_TARGET_DIR=/tmp/magpie-ui-target cargo +1.99.1 test \
  --locked --manifest-path apps/desktop/Cargo.toml --features visual-test --lib -- --test-threads=1
CARGO_TARGET_DIR=/tmp/magpie-ui-target cargo +1.99.1 run \
  --locked --manifest-path apps/desktop/Cargo.toml \
  --features visual-test --example render_preview -- \
  --output /tmp/magpie-ui-review --all --size 1280x720 --locale zh-CN
```

新增 `Desktop visual checks` 工作流使用隔离数据、Noto CJK 与 Mesa 软件 Vulkan，记录源码版本、GPUI 原始渲染 PNG、渲染清单和检查日志。它不启动真实账户服务，也不发布安装包。

GPUI Scene 截图用于核对生产组件的排版、字体和像素；操作系统窗口、IME、读屏及用户视觉认可分别验收，不由离屏截图推定。
